Compact Windows player for animation reference footage and playblasts.

## Install

Download `TrieFrameViewer-Setup-1.0.0-x64.exe` from the assets below and run it on
64-bit Windows 10 or 11. The installer includes the required runtime libraries;
Python, Qt, and development tools are not required. Installation is per user.
Save your project and close FrameViewer before updating an existing installation.

This repository is private. Downloads require a GitHub account with repository access.
The installer is unsigned, so Windows may show an unknown-publisher prompt.

## Included

- Forward/reverse playback, frame stepping, speed control, looping, and playback ranges.
- RAM frame caching, GPU texture reuse, and optional hardware decoding.
- Timeline clicks and drags preserve playing or paused state.
- Frame bookmarks with name tooltips and right-click rename, move, or delete.
- `.tfv` projects preserve bookmarks and review settings; save names follow the media name.
- Pan, zoom, rotation, flipping, dark/light themes, and keyboard shortcuts.
- Optional video context-menu integration in Preferences.
- Debug Mode shows live RAM, VRAM, and shared GPU memory usage.
- Save prompts require bookmarks; changing playback speed does not trigger a prompt.

## Current limits

- Reverse playback is silent. Forward playback and scrubbing use the cached audio
  beginning (about 5 minutes 50 seconds with the default audio budget).
- Image sequences currently use 24 fps. Exact variable-frame-rate indexing and
  HDR/OCIO workflows are not supported.
- Validation covers local Windows playback, audio, bookmarks, preferences, and
  installer/runtime checks. A separate clean-machine/VM check has not been completed.
