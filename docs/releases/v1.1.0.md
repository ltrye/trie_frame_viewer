## Cinema Mode

- Toggle **Playback → Cinema Mode**, or press **F11**, to fill the screen with video
  and hide the menu, title bar, viewer tools, timeline, and memory overlay.
- Move the mouse to reveal the timeline and playback controls over the video. The
  video keeps the same size when the controls appear or disappear.
- Controls hide after two seconds of inactivity. Hovering the controls, editing a
  frame field, dragging, or using a menu keeps them available.
- Press F11 or Esc to exit and restore the previous window state, including maximized.
- Playing footage continues playing; paused footage stays paused.
- F11 now defaults to Cinema Mode. Ordinary fullscreen remains in the Video menu,
  and shortcuts can be customized in Preferences.

## Install

Save your project and close FrameViewer, then run `TrieFrameViewer-Setup-1.1.0-x64.exe`.
Windows 10/11 x64 is required; runtime libraries are included. The installer is unsigned.
This private repository's downloads require an invited GitHub account.

Other features and playback limitations are unchanged from v1.0.0.
