## Cinema Mode layout

- The timeline and playback controls now stay visible below the video in Cinema Mode,
  using the same layout as the normal window.
- Mouse movement and inactivity no longer show or hide controls. Controls never cover
  the video.
- F11 and Esc still restore the previous window state. Playback and pause state are
  preserved when entering or leaving Cinema Mode.

## Install

Save your project and close FrameViewer, then run `TrieFrameViewer-Setup-1.1.1-x64.exe`.
Windows 10/11 x64 is required; runtime libraries are included. The installer is unsigned.
This private repository's downloads require an invited GitHub account.
