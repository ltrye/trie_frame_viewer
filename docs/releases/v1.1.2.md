## Seeking and scrubbing

- Foreground seeks deliver the requested frame without first copying intermediate
  frames into the cache. Cache warming continues during idle time.
- Continuous drag previews share a seek session, allowing useful decoding to
  finish while newer inputs replace the pending target.
- Releasing the mouse requests the exact selected frame and rejects older previews.
  A short input quiet period also finalizes callers that do not send a release.
- Playback/pause state, playback speed, direction, and reverse-playback lookbehind
  caching are preserved. Paused scrub audio follows delivered previews.
- Default cache limits remain 512 MiB RAM and 64 MiB GPU textures.

## Install

Save your project and close FrameViewer, then run `TrieFrameViewer-Setup-1.1.2-x64.exe`.
Windows 10/11 x64 is required; runtime libraries are included. The installer is unsigned.
This private repository's downloads require an invited GitHub account.
