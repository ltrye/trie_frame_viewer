## Window fix

- Always on Top now changes only the Windows topmost state. Toggling it preserves
  the native title bar, window decorations, size, and normal/maximized/Cinema state.

## Export selected range

- Choose **Tools → Export Time range to new clip…** to save the inclusive Start–End
  range as a new H.264/AAC MP4. The suggested filename includes the media name and
  displayed frame numbers.
- Exports run asynchronously with progress and Cancel controls. They use normal
  source speed and source audio, independently of review volume, playback speed,
  audio offset, zoom, rotation, and flips. Image sequences export silently at 24 fps.
- Non-keyframe cuts are re-encoded. Odd image dimensions are padded by one pixel
  where needed for H.264. Export does not modify bookmarks or project state.
- Original media cannot be replaced. Existing output files remain intact if the
  export fails or is cancelled; a complete clip is committed only after encoding.

## Validation

Validation: 28 core checks, 5 native audio checks, 7 export checks, and the full native
UI smoke test passed. Export checks also passed against 29.97 fps and 1080p long-GOP
fixtures. A visible Windows test verified repeated topmost toggles in normal,
maximized, and Cinema Mode windows.

## Install

Save your project and close FrameViewer, then run `TrieFrameViewer-Setup-1.2.0-x64.exe`.
Windows 10/11 x64 is required; runtime libraries and the exporter are included.
The installer is unsigned. Downloads require an invited account for this private repository.
