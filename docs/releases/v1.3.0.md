## Export current video to MP4

- **Tools → Export current video to MP4…** exports the complete loaded video,
  independently of the selected playback range.
- Resolution defaults to **Full HD (1920 × 1080)**. The export dialog also offers
  HD (1280 × 720), QHD (2560 × 1440), 4K (3840 × 2160), and source resolution.
- Aspect ratio is preserved; black bars fill any unused output area. Source frame
  rate and audio are preserved. Review speed, volume, and view transforms do not
  change the export.
- Suggested filenames include the media name and output resolution. Exports share
  the existing progress/cancellation controls and protect original media and
  existing destination files on failure or cancellation.
- The time-range export command continues to use the selected Start/End frames
  at source resolution.

## Validation

28 core tests, 5 native audio tests, 9 export tests, and the full native
UI smoke test passed. Checks cover full-video output independent of the review
range, 1920 × 1080 dimensions, complete frame/audio duration, resolution selection,
and aspect-preserving portrait scaling with padding.

## Install

Save your project and close FrameViewer, then run `TrieFrameViewer-Setup-1.3.0-x64.exe`.
Windows 10/11 x64 is required; runtime libraries and the exporter are included.
The installer is unsigned. Downloads require an invited account for this private repository.
