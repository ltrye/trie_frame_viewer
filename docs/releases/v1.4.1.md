## Timeline cache indicator

The cache coverage indicator below the timeline is now visible only while
Preferences → Debug Mode is enabled. Changing Debug Mode updates it immediately.
Frame caching, playback range, playhead and bookmark markers keep their normal behavior.

Verified the production app with loaded media in both Debug Mode states.

Save your project and close FrameViewer before running `TrieFrameViewer-Setup-1.4.1-x64.exe`.
